# Command Explanations & Transparency Rule

## Rule
Whenever running or introducing new terminal commands, CLI tools, scripts, or flags (such as `git`, `prisma`, `npx`, `tsc`, `npm`, or custom shell scripts):
1. **Explain the purpose**: Briefly explain what the command does before or after running it.
2. **Break down flags/options**: Clearly define what individual arguments and flags mean (e.g., `--noEmit`, `-b`, `-u`, `--name`).
3. **Provide context**: Explain why this command is being executed in the context of the user's task.
